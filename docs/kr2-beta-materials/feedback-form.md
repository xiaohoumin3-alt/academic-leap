## 六、反馈类型分类（数字反馈系统用）

### 6.1 功能建议 (Feature Request)

**适用场景**: 用户希望产品增加的新功能或改进现有功能

**示例**:
- "希望能有错题本功能"
- "希望能查看历史学习记录"
- "希望能有语音读题功能"

**收集要点**:
- 功能描述
- 使用场景
- 期望效果
- 需求强度（1-5分）

### 6.2 Bug报告 (Bug Report)

**适用场景**: 产品功能异常或不符合预期的情况

**示例**:
- "点击答案没有反应"
- "题目显示乱码"
- "答案正确但系统判定错误"

**收集要点**:
- 问题描述
- 复现步骤
- 环境信息
- 截图/录屏
- 发生频率

### 6.3 用户体验 (UX Feedback)

**适用场景**: 用户对产品使用过程中的感受和意见

**示例**:
- "界面太复杂，找不到在哪里提交答案"
- "题目做完后不知道下一步该做什么"
- "鼓励不够，做对了也没成就感"

**收集要点**:
- 具体感受
- 遇到困难的地方
- 改进建议
- NPS评分（0-10）

### 6.4 性能问题 (Performance Issue)

**适用场景**: 产品运行时的性能、稳定性问题

**示例**:
- "加载很慢，要等好几秒"
- "做题的时候页面卡顿"
- "页面经常白屏"

**收集要点**:
- 问题现象
- 网络环境
- 设备信息
- 时间戳

## 附录：用户访谈问题清单

当需要进行用户访谈时，使用以下问题清单：

```
### 开场（5分钟）
1. 请简单介绍一下您自己（年级、使用时长）
2. 您通常在什么场景下使用这个App？

### 核心体验（20分钟）
3. 您最近一次使用App是做什么？感觉怎么样？
4. 有什么功能让您觉得特别好用？
5. 有什么功能让您感到困惑或不便？

### 深入探索（10分钟）
6. 如果让您提一个改进建议，您会说什么？
7. 您有没有向朋友推荐过这个App？为什么/为什么不？

### 结束（5分钟）
8. 您对这个App整体满意吗？给个分数（0-10分）
9. 还有什么想说的吗？

### 记录要点
- 用户原话（verbatim quotes）
- 情绪反应
- 未表达的需求
```
