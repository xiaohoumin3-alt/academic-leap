## 开发任务拆解

### Phase 1: AI 题目生成 (1-2 周)

**目标：** 结合模板和 AI，生成更丰富的题目

```
lib/ai/question-generator/
├── index.ts           # 主入口
├── template-filler.ts # AI 填充模板
├── free-form.ts       # AI 自由生成
└── validator.ts       # 题目验证
```

**任务：**
- [ ] 1.1 设计 AI 生成 Prompt 模板
- [ ] 1.2 实现 template-filler（AI 填充现有模板）
- [ ] 1.3 实现 free-form（AI 自由生成）
- [ ] 1.4 添加题目验证（数学正确性检查）
- [ ] 1.5 单元测试

### Phase 2: UOK 推荐引擎 (1-2 周)

**目标：** 基于学生表现推荐最合适的下一题

```
lib/recommendation/
├── index.ts              # 主入口
├── uok-selector.ts       # UOK 题目选择
├── difficulty-matcher.ts # 难度匹配
└── next-question.ts      # 下一题推荐
```

**任务：**
- [ ] 2.1 设计推荐算法（结合 IRT + Bandit）
- [ ] 2.2 实现 UOK 选择器（最近发展区）
- [ ] 2.3 实现难度匹配器
- [ ] 2.4 集成 RL 探索策略
- [ ] 2.5 单元测试

### Phase 3: 学习路径端到端 (1 周)

**目标：** 完整的学习流程

```
lib/learning-flow/
├── index.ts           # 主流程
├── session.ts         # 学习会话
├── progress-tracker.ts # 进度跟踪
└── path-updater.ts    # 路径更新
```

**任务：**
- [ ] 3.1 设计学习会话流程
- [ ] 3.2 实现进度跟踪
- [ ] 3.3 实现路径动态更新
- [ ] 3.4 集成测试

### Phase 4: 知识点扩展 (2-3 周)

**目标：** 覆盖初中数学核心知识点

**优先级：**
1. 代数：一次方程、不等式、函数
2. 几何：三角形、圆、相似
3. 统计：概率、数据分析

**任务：**
- [ ] 4.1 创建知识点映射表
- [ ] 4.2 为每个知识点创建模板
- [ ] 4.3 添加验证数据
