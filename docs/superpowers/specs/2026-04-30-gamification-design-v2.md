# 学力跃迁 - 游戏化设计方案 V2

**版本**: v2.0
**日期**: 2026-04-30
**核心调整**: 社交优先 + 家长友好主题

---

## 一、设计原则更新

### V1 → V2 核心变化

| 维度 | V1 | V2 |
|------|----|----|
| 核心驱动 | 单人游戏化 | **社交装逼** |
| 主题数量 | 4个 | **4个（家长友好）** |
| 连胜系统 | 有防护 | 有防护+可炫耀 |
| 音效 | 默认开启 | **默认静音** |
| 文案风格 | "学习"话术 | **中学生话术** |

### 新增核心原则

**4. 社交优先原则**
> 能和同学比较、能炫耀、能"虐"别人的功能优先级最高

**5. 家长友好原则**
> 所有主题必须让家长觉得"对孩子成长有益"，而非"分心"

### 2.2 主题详细设计

#### 🏰 魔法学院（魔法学院）

**家长卖点**：像哈利波特一样的学习体验

**核心叙事**:
```
你收到了魔法学院录取通知书。
每个科目是一个数学领域，
上课学习（答题）掌握魔法咒语，
参加考试挑战获得学院积分，
最终目标：成为魔法大师！
```

**视觉元素**：
- 学院徽章（四个学院可选）
- 魔法书（知识点）
- 魔法值条（相当于进度）
- 学院排行榜（社交核心）

**社交设计**：
- 四个学院对抗（像哈利波特）
- 学院积分榜
- "为学院而战"的荣誉感

#### 👔 职业养成（职业养成）

**家长卖点**：提前体验职业，建立目标感

**核心叙事**:
```
你是一名刚入职的实习生，
想要成为行业顶尖专家。

每个项目是一个数学知识点，
完成任务（答题）获得职业经验，
升级解锁更高职位，
最终目标：成为行业领袖！
```

**可切换职业**：
- 🔬 科学家（理科导向）
- 🏥 医生（家长最爱）
- 👨‍💻 工程师（程序员导向）
- 📊 数据分析师

**视觉元素**：
- 职业徽章
- 办公室场景（随职位升级）
- 技能树（知识点可视化）

**社交设计**：
- 职业排行榜（医生/工程师分开排）
- "谁先成为主任医师"竞争
- 跨职业挑战

#### 🏎️ 极限竞速（极限竞速）

**家长卖点**：竞技体育精神，目标感和拼搏

**核心叙事**:
```
你是一名赛车手，
每条赛道是一个数学知识树。

练习（答题）提升车手技能，
比赛获得排名和奖金，
升级赛车，参加更高级别赛事，
最终目标：世界冠军！
```

**视觉元素**：
- 赛车（可升级换装）
- 赛道地图（知识点可视化）
- 速度仪表盘（进度）
- 领奖台（排行榜）

**社交设计**：
- 全服排行榜
- 车队系统（组队）
- 实时PK（答题对战）

#### 🕵️ 特工行动（特工行动）

**家长卖点**：智力挑战，培养专注力和反应

**核心叙事**:
```
你是特工组织的新成员，
正在接受训练。

每个行动是一个数学任务，
完成任务（答题）获得情报和技能，
晋升军衔，解锁更高级别任务，
最终目标：成为王牌特工！
```

**视觉元素**：
- 特工徽章（军衔）
- 任务地图（世界地图）
- 情报收集进度
- 行动档案

**社交设计**：
- 特工排行榜（军衔排名）
- 小队任务（组队）
- 特工对战（答题PK）

## 三、社交装逼系统（新增核心）

### 3.1 排行榜设计

#### 全服排行榜（残酷版）

```
┌─────────────────────────────────────┐
│  🏆 学院风云榜 - 本周               │
├─────────────────────────────────────┤
│  1. 张小明     魔法学院 Lv.12      │
│     通关知识点: 45 | 连胜纪录: 15  │
│                                     │
│  2. 李华      职业养成 Lv.11      │
│     通关知识点: 42 | 连胜纪录: 12  │
│                                     │
│  ...                                │
│                                     │
│  10. 王小红   极限竞速 Lv.9        │
│                                     │
│  ────────────────────────────────── │
│  你还差 3 名就能进入前十！          │
└─────────────────────────────────────┘
```

**设计要点**：
- 只显示前10名（制造稀缺感）
- 显示关键数据（让有野心的人有目标）
- "你差X名进入前十"（激励追赶）

#### 班级排行榜（核心社交圈）

```
┌─────────────────────────────────────┐
│  📊 三年2班 - 本周排名             │
├─────────────────────────────────────┤
│  1. 陈小明    1250 分   📈+2       │
│  2. 林小红    1180 分   📈+1       │
│  3. 张小华    1150 分   ─         │
│  4. 你        1120 分   📈+5 🔥    │
│  5. 王小明    1080 分   📉-2       │
│                                     │
│  全班平均分: 985                   │
│  你超过了全班 60% 的同学           │
└─────────────────────────────────────┘
```

**设计要点**：
- 同班同学竞争（最强社交动力）
- 显示升降名次
- 百分比排名（"你超过了X%"）


## 四、连胜系统（防护版）

### 4.1 连胜设计

| 连胜数 | 效果 | 特殊加成 |
|--------|------|----------|
| 3连对 | "状态来了！" | 1.5x积分 |
| 5连对 | "势不可挡！" | 2x积分 + 特效动画 |
| 10连对 | "超神模式！" | 3x积分 + 全服广播 |

### 4.2 防护机制（防止刷分）

#### 只计入推荐题目

```typescript
if (question.isRecommended) {

} else {
  // 自选简单题，连胜不计入
  showHint('推荐题答题才能计入连胜哦');
}
```
